  ✓ Open your browser

┌──────────────────────────────────────────────────────────────────────┐
│  TROUBLESHOOTING                                                     │
└──────────────────────────────────────────────────────────────────────┘

❌ Error: "Cost/Time estimation service error"

   CAUSE: Web app started before microservices
   
   FIX:
   1. Close all 3 command windows
   2. Wait 5 seconds
   3. Run START_HERE.bat again
   4. Wait full 20 seconds before testing


❌ Error: "ModuleNotFoundError: No module named 'httpx'"

   FIX:
   py -3.11 -m pip install httpx


❌ Error: "Port already in use"

   FIX:
   Stop-Process -Name python -Force
   Then run START_HERE.bat again


❌ Error: One service window closes immediately

   CAUSE: Error in that service
   
   FIX:
   1. Open PowerShell
   2. cd D:\SE-project
   3. Run the service manually to see error:
      py -3.11 trust_score_service.py
      py -3.11 cost_time_service_api.py
      py -3.11 web_app.py
